parcelClouds Class Reference

List of parcel clouds, with the same interface as an individual parcel cloud. Is a mesh object, so mesh change hooks are provided and will be applied to the contained cloud. This is the object that should be constructed by a solver in order to support the coupled simulation of multiple clouds. An fvModel should *not* construct this object, as that would nest two mesh objects. An fvModel should construct the base parcelCloudList instead. More...

Detailed Description

List of parcel clouds, with the same interface as an individual parcel cloud. Is a mesh object, so mesh change hooks are provided and will be applied to the contained cloud. This is the object that should be constructed by a solver in order to support the coupled simulation of multiple clouds. An fvModel should *not* construct this object, as that would nest two mesh objects. An fvModel should construct the base parcelCloudList instead.
