24Class
25 Foam::surfaceNormalUniformFixedValueFvPatchVectorField
26
27Description
28 Surface-normal fixed value vector boundary condition
29
30 in which the vector field is obtained by scaling the patch normals
31 by the evaluated scalar Function1 provided.
32
33Usage
34 \table
35 Property | Description | Required | Default value
36 uniformValue | uniform value | yes |
37 \endtable
38
39 Example of the boundary condition specification:
40 \verbatim
41 <patchName>
42 {
43 type surfaceNormalUniformFixedValue;
44 uniformValue constant -0.2; // 0.2 INTO the domain
45 }
46 \endverbatim
47
48 Note:
49 Sign conventions:
50 - the value is positive for outward-pointing vectors
51
52See also
53 Foam::fixedValueFvPatchField
