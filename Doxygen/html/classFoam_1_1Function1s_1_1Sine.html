Detailed Description

template<class Type>
class Foam::Function1s::Sine< Type >

Templated sine function with support for an offset level.

where

= Description Data type Default
= Amplitude Function1<Type>
= Frequency scalar
= Start scalar 0
= Offset level Function1<Type>

Example for a scalar: 

        <name> sine;
        <name>Coeffs
        {
            amplitude 2e-7;
            frequency 10;
            start     0;
            level     2e-6;
        }

Example for a vector: 

        <name> sine;
        <name>Coeffs
        {
            amplitude (1 0.1 0);
            frequency 10;
            start     0;
            level     (10 1 0);
        }
