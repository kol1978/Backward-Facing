Detailed Description

This fvModel represents conduction through a solid region. It solves for the electric potential, calculates the current, and applies the corresponding Joule heating source to the energy equation. It requires the user to specify the electric potential field phi in the zero directory.

Usage
Example usage with a constant scalar conductivity: 
solidElectricalConduction
{
    type            solidElectricalConduction;

    sigma           35.5e6; // <-- 'sigma<scalar>' is also accepted
}

Example usage with a constant tensor conductivity: 

solidElectricalConduction
{
    type            solidElectricalConduction;

    sigma<tensor>   (35.5e6 0 0 0 35.5e6 0 0 0 35.5e6);
}

Example usage with a functional scalar conductivity, and writing the conductivity out for post-processing: 

solidElectricalConduction
{
    type            solidElectricalConduction;

    sigma
    {
        type        distanceFunction;

        function
        {
            type        polynomial;
            coeffs      (35.5e6 1e9);
        }

        direction   (0 1 0);
    }

    writeSigma      yes;
}
