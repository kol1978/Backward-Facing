Detailed Description

Controls the time-step to the minimum nucleation time scale. A specific nucleation model can be specified, otherwise it will scan for and use all the nucleation fvModels in operation.

Note that this function only does anything if time step adjustment is enabled in the controlDict.

Example of function object specification: 

adjustTimeStepToNucleation
{
    type            adjustTimeStepToNucleation;
    libs            ("libmultiphaseEulerFunctionObjects.so");
    maxCo           0.1;
}
Usage
Property Description Required Default value
type type name: adjustTimeStepToNucleation yes
model name of the nucleation fvModel no
maxCo maximum nucleation "Courant" number no 1
