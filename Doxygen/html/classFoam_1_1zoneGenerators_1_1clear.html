Detailed Description

A zoneGenerator which clears all existing zones from the mesh.

Usage
Property Description Required Default value
type Type: clear yes

Example: 

        clearAllZones
        {
            type        clear;
        }

When called from the top-level of the createZonesDict or zonesGenerator files which is the most likely use the simpler syntax to clear all the zones can be used: 

        clear;
See also
zoneGenerators::remove
