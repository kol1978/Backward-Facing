Detailed Description

Square pulse function. Takes a value of 0 before start, then rises instantaneously to 1, remains at 1 for duration, then drops instantaneously back to 0.

Usage
    <name> squarePulse;
    <name>Coeffs
    {
        start     10;
        duration  20;
    }
or 
    <name>
    {
        type      squarePulse;
        start     10;
        duration  20;
    }

Where:

Property Description Required Default value
start Start time no 0
duration Duration yes
