Detailed Description

Description This function calculates the fluid and acceleration forces and moments at a series of section-planes through a given rigid body. It writes the result into a graph which can be used to construct (potentially just a part of) a shear force and bending moment diagram. Points in the graph are graded to approximately match the resolution of the mesh.

The cut-planes are defined as normal to an axis in the local coordinate system of the rigid body, and the line of the graph extends along the axis from an origin defined in the same local coordinate system. Forces and moments are calculated on the side of the plane on which coordinates have a positive axis-component.

Note that this function does not take into account the effect of joints or restraints attached to the body, so if these are applied then the shear force and bending moment diagrams generated will be somewhat incomplete. Note that ramping, acceleration relaxation, and solution tolerance can also result in components of the forces and moments to be missing from the output.

Example of function object specification: 

    rigidBodySectionalForceGraph
    {
        type            rigidBodySectionalForceGraph;
        libs            ("librigidBodyForces.so");
        body            beam;
        patches         (beam);
        axis            x;
        nPoints         101;
        setFormat       raw;
        writeControl    writeTime;
    }
