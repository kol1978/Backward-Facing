Detailed Description

template<class Type>
class Foam::codedFixedValueFvPatchField< Type >

Fixed value boundary condition evaluated from the code provided.

which is compiled, linked and executed automatically at run-time.

The optional name entry specifies the name of the code generated from the template, if not provided the it constructed as <field name>_<patch name> for single region cases or <region name>_<field name>_<patch name> for multi-region cases.

Usage
Example: 
<patchName>
{
    type            codedFixedValue;

    value           uniform 0;

    name            rampedFixedValue;   // Optional name of generated code

    code
    #{
        operator==(min(10, 0.1*this->time().value()));
    #};

    // codeInclude
    //#{
    //    #include ".H"
    //#};

    // codeOptions
    //#{
    //    -I$(LIB_SRC)/finiteVolume/lnInclude
    //#};
}
