Detailed Description

template<class Type>
class Foam::maxLagrangianFieldSource< Type >

This source condition provides the maximum value of the primitive type; i.e., all components set to vGreat.

Usage
Example specification: 
<LagrangianModelName>
{
    type            max;
}
