This boundary condition provides a turbulence dissipation, (epsilon) inlet condition based on a specified mixing length. The patch values are calculated using:

Usage
Property Description Required Default value
mixingLength Length scale [m] yes
phi flux field name no phi
k turbulence kinetic energy field name no k
Cmu Turbulence model coefficient no 0.09

Example of the boundary condition specification: 

    <patchName>
    {
        type            turbulentEpsilon;
        mixingLength    0.005;
        value           uniform 200;   // placeholder
    }

Note: In the event of reverse flow, a zero-gradient condition is applied
