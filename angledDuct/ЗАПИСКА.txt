Это параметрическая 3D‑сетка для канала с наклонным входом и пористой зоной — нетипичная, но очень интересная конструкция, использующая современные возможности blockMeshDict из OpenFOAM v2312.

Что это геометрически
Канал из трёх последовательных участков:

        ┌─────────────────────┐
        │      inlet (135°)    │
        │      30×20×20        │
        └────────┬────────────┘
                 │
    ┌────────────┴────────────┐
    │     porosity (100 мм)    │
    │     20×20×20              │
    └────────────┬────────────┘
                 │
        ┌────────┴────────────┐
        │    outlet (100 мм)   │
        │    20×20×20          │
        └─────────────────────┘
Вход (inlet) приходит под углом 135° к оси пористой зоны — то есть поток заходит «сбоку‑сверху», а не прямо.
Пористая зона (porosity) — прямой участок 100×50×50 мм, где будет работать модель пористости.
Выход (outlet) — продолжает прямой участок ещё на 100 мм.
После построения вся сетка поворачивается на 45° вокруг оси Z (блок transform), чтобы пористая зона оказалась не выровненной по главным осям.
Зачем: чтобы проверить, корректно ли модель пористости работает в произвольной системе координат, а не только вдоль X/Y/Z.
