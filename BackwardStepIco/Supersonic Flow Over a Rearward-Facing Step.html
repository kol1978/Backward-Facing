Сверхзвуковой поток над ступенью, обращенной назад

Описание задачи

Код WIND был валидирован на основе измерений сверхзвукового потока идеального газа над ступенью, обращенной назад. Условие ступенчатого обтекания, при котором ступенька обращена назад, является фундаментальным тестовым случаем для оценки результатов, полученных с помощью CFD-кодов, в области расширяющегося веера между потоком в свободном режиме и ударной волной отрыва потока, а также в области относительно постоянного давления между ударной волной отрыва потока и слоем сдвига. Код WIND с зональными граничными условиями был использован для определения сверхзвукового обтекания геометрии, показанной ниже, и результаты были сопоставлены с данными, представленными Смитом (ссылка 1). Был выбран тестовый сценарий с числом Маха на входе 2,5 (Re=460 000/дюйм). При таких условиях в туннеле поток должен быть ламинарным на большей части передней пластины. Переход к турбулентному режиму должен происходить в сдвиговом слое над задней ступенькой.


Скачать tar-файл

Все архивные файлы этого проверочного примера, включая входные файлы скрипта, на которые есть ссылки ниже, доступны в сжатом tar-файле Unix RearwardStep.tar.Z. Доступ к файлам можно получить с помощью следующих команд:

uncompress RearwardStep.tar.Z
tar -xvof RearwardStep.tar

Геометрическая модель

Высота ступеньки, обращенной назад, составила 0,443 дюйма. Моделируемая область простиралась на 4,0 дюйма вверх по течению от уступа, на 12 дюймов вниз по течению от уступа и на 6,25 дюйма вверх от уступа.


Сетки

Сетка была разделена на две вычислительные области с непрерывными линиями сетки на границе. Область выше уступа была смоделирована с использованием сетки I=30 x J=40 (I — вдоль потока, J — перпендикулярно стенке). В области ниже уступа использовалась сетка 60x79. Первая точка на вязких стенках соответствовала значению y+ примерно 1,0.

Начальные и граничные условия

Были заданы следующие граничные условия:

    Зона 1:
    Левая граница — приток в свободном потоке
    Правая граница — соединение с сеткой в зоне 2
    Нижняя граница — вязкая стенка
    Верхняя граница — невязкая стенка

    Зона 2:
    Левая граница — соединена с сеткой в зоне 1 для J=40–79,
    вязкая стенка для J=1–39
    Правая граница — свободный поток
    Нижняя граница — вязкая стенка
    Верхняя граница — невязкая стенка

Исходные условия:

    Зона 1:
    Условия свободного потока: скорость 2,5 Маха, статическое давление 2,227 фунта на кв. дюйм и статическая температура 304,5 °F.
    Зона 2:
    Давление в свободном потоке и произвольная температура: статическое давление P = 2,227 фунта на кв. дюйм, статическая температура T = 275,4 градуса. R
    Mach 0,0 за ступенью (чтобы избежать проблем на поверхности ступени)
    Mach 2,5 над ступенью

Входные параметры и файлы

Стратегия расчета заключалась в том, чтобы начать расчет потока над ступенью в зоне 1 и зоне 2 при статическом давлении, температуре и числе Маха набегающего потока, в то время как поток за ступенью, в зоне 2, был инициализирован как невозмущенный при статических условиях набегающего потока. Такая инициализация была призвана обеспечить развитие области рециркуляции за ступенью без возникновения проблем на задней стенке ступени. Использовался полный неявный решатель с локальным шагом по времени при числе Куранта — Фридрихса — Леви 0,40.

Стратегия вычислений

Входной файл WIND (back.dat) было:
    Supersonic Backward Facing Step
    Mach 2.5 Ts=304.5 deg. R Ps=2.227 psi
    WIND Validation 10/9/97
    FREESTREAM STATIC 2.5 2.227 304.5 0.0 0.0
    ARBITRARY INFLOW ( initialize zone 2  behind step for zero flow)
      STATIC
      ZONE 2
      IJK_RANGE 1 61 1 40 1 1 0.0 2.227 275.4 0.0 0.0
    END INFLOW
    IMPLICIT BOUNDARY ON
    CYCLES 1000
    CFL# 0.4
    TURBULENCE sst
    END 

Блок "ПРОИЗВОДИТЕЛЬНЫЙ ПРИТОК" предназначен только для инициализации и игнорируется при перезапуске решения, то есть когда уже существует действительный .cfl файл.

Вычисления

Вычисления выполнялись на SGI Indigo 2 с использованием компилятора версии 5.3. Код WIND был запущен с помощью скрипта WIND с указанием версии кода по умолчанию. Ответом на все запросы имен файлов, то есть .dat, .cgd, .cfl, .lis, было корневое имя "back" (обратите внимание на имя входного файла выше). Для выполнения вычислений с использованием модели турбулентности SST и расчета турбулентного напряжения использовался решатель по умолчанию. Применялись неявные граничные условия. Переменные потока в зоне 1 сходятся с остаточным значением L2 6,6e-06, а переменные турбулентности — с остаточным значением 6,4e-08. Переменные потока в зоне 2 сходятся с остаточным значением 2,0e-04, а переменные турбулентности — с остаточным значением 3,2e-07.


Пост-обработка

Графические результаты были получены с помощью FAST. Файл сетки PLOT2D был получен с помощью программы b4wind, которая конвертировала файл back.cgd в неформатированный файл plot2d с именем back_2zone.p2d. Два файла решений PLOT2D были созданы с помощью программы cfpost . Первый файл создается путем ввода cfpost < cfpost_flo.inp. В результате создается стандартный файл решения PLOT2D, back_prt.2d. Второй файл решения PLOT2D создается с помощью команды cfpost < cfpost_prt.inp, которая создает файл back_prt.2d, содержащий величину скорости, статическое давление, нормализованное к давлению торможения в натекающем потоке (см. следующий рисунок), температуру и плотность.



Сравнение результатов

В качестве параметров валидации, выбранных для исследования, были выбраны статическое давление на поверхности ниже по течению от ступени и расположение ударной волны при повторном присоединении. Ниже показаны значения статического давления на поверхности, рассчитанные с помощью WIND с использованием двухпараметрической модели турбулентности SST. На этом рисунке приведены результаты, полученные с помощью ранней версии NPARC (ссылка 2) и WIND, в сравнении с экспериментальными данными. Код ВЕТРА немного завысил прогноз падения давления на поверхности от значения набегающего потока до углового значения в области отрыва (базовое давление) примерно на 5 процентов. Вероятно, это происходит из-за того, что точка перехода экспериментально неизвестна и не совсем точно предсказана естественным переходом модели турбулентности. Однако этот завышенный прогноз ближе к экспериментальным результатам, чем предыдущие заниженные прогнозы падения давления с использованием кодов AEDC PARC, TUFF и GASP (Ссылки). 2 и 3), в которых использовались модели Болдуина Ломакса, K-E и Чебечи и Смита соответственно. Остальные данные о прогнозируемом давлении, полученные с помощью WIND, в точности соответствуют прогнозам.
