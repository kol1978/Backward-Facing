Detailed Description

Set up trapping for floating point exceptions (signal FPE).

Controlled by two env vars:

  • FOAM_SIGFPE
    Exception trapping
  • FOAM_SETNAN
    Initialisation of all malloced memory to NaN. If FOAM_SIGFPE also set, this will cause usage of uninitialised scalars to trigger an abort.
