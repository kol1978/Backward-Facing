Detailed Description

template<class Type>
class Foam::Function1s::Uniform< Type >

Templated function that returns a constant value.

Provides backward-compatibility for cases where a field is spatially "uniform" and may be treated as a constant value.

Usage
For entry <name> returning the value

: 

    <name>    uniform  <value>
