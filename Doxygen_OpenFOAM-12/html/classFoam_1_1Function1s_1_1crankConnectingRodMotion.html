Detailed Description

Crank and connecting-rod motion function for piston engines etc.

value returns the current piston position as a function of the crank-angle in degrees.

Usage: 

    <name>
    {
        type            crankConnectingRodMotion;

        conRodLength    0.2;
        stroke          0.12;
    }
