Detailed Description

Turbulent boundary-layer function pow(yHat, exponent)

where yHat is the normalised distance to the wall and the optional exponent defaults to 1/7.

Usage: 

    <name> turbulentBL;

or 

    <name>
    {
        type      turbulentBL;
        exponent  0.143;
    }
