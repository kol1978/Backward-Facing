Detailed Description

template<class LimiterFunc>
class Foam::limitedCubicLimiter< LimiterFunc >

Class with limiter function which returns the limiter for the TVD limited centred-cubic interpolation scheme based on r obtained from the LimiterFunc class.

Used in conjunction with the template class LimitedScheme.
