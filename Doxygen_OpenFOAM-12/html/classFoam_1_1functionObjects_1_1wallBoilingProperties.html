Detailed Description

This function looks up wall boiling wall functions and collects and writes out out the following data:

  • Bubble departure diameter
  • Bubble departure frequency
  • Nucleation site density
  • Effective liquid fraction at the wall
  • Quenching heat flux
  • Evaporative heat flux

Example of function object specification: 

writeWallBoilingProperties
{
    type            wallBoilingProperties;
    libs            ( "libmultiphaseEulerFunctionObjects.so" );
    writeControl    writeTime;
    phase           liquid;
}
