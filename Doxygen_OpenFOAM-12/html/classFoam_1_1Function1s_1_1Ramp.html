Detailed Description

template<class Function1Type>
class Foam::Function1s::Ramp< Function1Type >

Ramp function base class for the set of scalar functions starting from 0 and increasing monotonically to 1 from start over the duration and remaining at 1 thereafter.

Usage
    <name> <rampFunction>;
    <name>Coeffs
    {
        start     10;
        duration  20;
    }
or 
    <name>
    {
        type      <rampFunction>;
        start     10;
        duration  20;
    }
or including a constant scaling factor: 
    <name>
    {
        type      scale;

        scale
        {
            type        <rampFunction>;

            start       0;
            duration    10;
        }

        value       100;
    }
for more details of scaling the ramp see Foam::Function1s::Scale.

Where:

Property Description Required Default value
start Start time no 0
duration Duration yes
See also
Foam::Function1 Foam::Function1s::Scale
