Detailed Description

This simple model generates a phase change between two phases calculated from the following expression:

= mass transfer rate per unit volume
= coefficient
= volume fraction of the source phase
Usage
Example usage: 
coefficientPhaseChange
{
    type            coefficientPhaseChange;

    phases          (liquid vapour);

    C               [kg/m^2/s] 0.1;
}
