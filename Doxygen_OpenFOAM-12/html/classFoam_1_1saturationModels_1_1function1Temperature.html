Detailed Description

Saturation vapour temperature in terms of the vapour pressure (in Pa). The saturation temperature in Kelvins is specified as a Foam::Function1 type, to enable use of, e.g. constant, polynomial, table values.

Examples:

    type function1;
    function polynomial
    (
        (308.0422       0)
        (0.0015096      1)
        (-1.61589e-8    2)
        (1.114106e-13   3)
        (-4.52216e-19   4)
        (1.05192e-24    5)
        (-1.2953e-30    6)
        (6.5365e-37     7)
    );

    type function1;
    function table;
    functionCoeffs
    {
        file                "filename.csv";
        format              csv;
        nHeaderLine         1;
        columns             (0 1);
        separator           ",";
        mergeSeparators     no;
        outOfBounds         clamp;
        interpolationScheme linear;
    };
