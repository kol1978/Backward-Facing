Detailed Description

Negate a dictionary variable by prefixing with neg.

E.g. 

    Umean 5.75;
    .
    .
    .
    inlet
    {
        type            uniformFixedValue;
        uniformValue    (#neg $Umean 0 0);
    }

Note the space required between the neg and the '$'
