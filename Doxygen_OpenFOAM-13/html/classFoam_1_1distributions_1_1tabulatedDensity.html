Detailed Description

Distribution in which the probability density function is given as a table of values.

Usage
Example usage: 
{
    type    tabulatedDensity;
    Q       0;
    distribution
    (
        (10e-6 0.0025)
        (12e-6 0.2795)
        (15e-6 2.3988)
        (19e-6 6.3888)
        (25e-6 10.3153)
        (31e-6 12.0030)
        (39e-6 10.8427)
        (50e-6 6.1333)
        (63e-6 3.4688)
    );

}
