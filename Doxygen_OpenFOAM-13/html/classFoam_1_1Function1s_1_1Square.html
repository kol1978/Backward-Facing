Detailed Description

template<class Type>
class Foam::Function1s::Square< Type >

Templated square-wave function with support for an offset level.

where

is the square-wave function in range with a mark/space ratio of

= Description Data type Default
= Amplitude Function1<Type>
= Frequency scalar
= Phase scalar 0
= Offset level Function1<Type>
= Mark/space ratio scalar 1

Example for a scalar: 

        <name> square;
        <name>Coeffs
        {
            amplitude 2e-7;
            frequency 10;
            start     0;
            level     2e-6;
            markSpace 0.5;
        }

Example for a vector: 

        <name> square;
        <name>Coeffs
        {
            amplitude (1 0.1 0);
            frequency 10;
            start     0;
            level     (10 1 0);
            markSpace 0.5;
        }
