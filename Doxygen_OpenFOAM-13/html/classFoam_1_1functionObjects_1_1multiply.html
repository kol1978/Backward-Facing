Detailed Description

Multiply a list of fields.

The operation can be applied to any volume or surface fields provided that the resulting multiplication does not produce a tensor of rank greater than two.

Example of function object specification: 

Ttot
{
    type            multiply;
    libs            ("libfieldFunctionObjects.so");
    fields          (rho U);
    result          rhoU;
    executeControl  writeTime;
    writeControl    writeTime;
}
