Detailed Description

Surface geometry with a tube shape, which can be used with snappyHexMesh. The geometry is formed from a line geometry, described by the edgeMesh (.eMesh) file format, to which a radius is applied to form a tube.

Usage
Property Description Required
file File describing the line (.eMesh) yes
radius Tube radius yes

Example specification in snappyHexMeshDict/geometry: 

        type       extrudedCircle;
        file       "line.eMesh";
        radius     5;
