Detailed Description

Rosin-Rammler distribution, scaled so that it spans between a specified minimum and maximum value, rather than from zero to infinity.

Usage
Example usage: 
{
    type    RosinRammler;
    Q       0;
    min     0.00001;
    max     0.00015;
    d       0.00014;
    n       2;
}
