LagrangianModels Class Reference

List of Lagrangian models, constructed as a (Lagrangian) mesh object. Provides similar functions to the models themselves and forwards them to each model in turn. This is the high level model interface used by clouds when constructing their injections and transport equations. More...

Detailed Description

List of Lagrangian models, constructed as a (Lagrangian) mesh object. Provides similar functions to the models themselves and forwards them to each model in turn. This is the high level model interface used by clouds when constructing their injections and transport equations.
