Detailed Description

A zoneGenerator which selects the faces returned by the given zoneGenerator that are aligned with the given normal.

The returned faceZone is oriented and provides the corresponding flipMap.

Usage
Property Description Required Default value
type Type: face yes
name Name of the zone no zoneGenerator name
normal Reference unit vector yes
tol cos angle tolerance yes
moveUpdate Switch to update after mesh motion no false

To create the faceZone floatingObjectBottom containing the faces of the floatingObject patch which point in the y-direction: 

        floatingObjectBottom
        {
            type        normal;

            normal      (0 1 0);
            tol         0.01;

            floatingObject
            {
                type        patch;
                patch       floatingObject;
            }
        }
