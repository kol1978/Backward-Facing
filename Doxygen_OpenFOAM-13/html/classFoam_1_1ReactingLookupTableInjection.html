Detailed Description

template<class CloudType>
class Foam::ReactingLookupTableInjection< CloudType >

Particle injection sources read from look-up table. Each row corresponds to an injection site.

( (x y z) (u v w) d rho mDot T cp (Y0..YN) // injector 1 (x y z) (u v w) d rho mDot T cp (Y0..YN) // injector 2 ... (x y z) (u v w) d rho mDot T cp (Y0..YN) // injector N );

where: x, y, z = global cartesian co-ordinates [m] u, v, w = global cartesian velocity components [m/s] d = diameter [m] rho = density [kg/m^3] mDot = mass flow rate [kg/s] T = temperature [K] cp = specific heat capacity [J/kg/K] Y = list of mass fractions
