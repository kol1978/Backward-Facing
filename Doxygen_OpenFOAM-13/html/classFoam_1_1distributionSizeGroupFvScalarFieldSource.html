Detailed Description

Source condition for size-group fractions that sets values corresponding to a given distribution.

Usage
Example of the source condition specification: 
<sourceName>
{
    type        distributionSizeGroup;
    distribution
    {
        type        RosinRammler;
        Q           0;
        min         1 [mm];
        max         15 [mm];
        d           14 [mm];
        n           2 [];
    }
}
