27Description
28 Templated base class for momentum cloud
29
30 - cloud function objects
31
32 - particle forces, e.g.
33 - buoyancy
34 - drag
35 - pressure gradient
36 - ...
37
38 - sub-models:
39 - dispersion model
40 - injection model
41 - patch interaction model
42 - stochastic collision model
43 - surface film model
