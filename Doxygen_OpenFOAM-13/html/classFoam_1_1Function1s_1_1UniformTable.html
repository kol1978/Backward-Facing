Detailed Description

template<class Type>
class Foam::Function1s::UniformTable< Type >

Tabulated property function that linearly interpolates between the UniformTable values.

Usage
Property Description
low Lower limit of the table
high Upper limit of the table
values Values, assumed uniformly distributed

Example for the density of water between 280 and 350K 

    rho
    {
        type    uniformTable;

        low    280;
        high   350;

        values
        (
            999.87
            991.53
            973.7
        );
    }
