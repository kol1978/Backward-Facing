Detailed Description

template<class Type>
class Foam::Function2s::Product< Type >

Function2 which returns the product of two independent Function1-s of the two input arguments. The two function1s are specified as value1 and value2.

Example to scale a table of vectors in the first argument with a ramp in the second argument: 

    <name>
    {
        type            product;
        value1<vector>  table
        (
            (0.00 (0 0 0))
            (0.25 (1 0 0))
            (0.50 (0 0 0))
        );
        value2<scalar>
        {
            type        linearRamp;
            start       1;
            duration    4;
        }
    }

Note that only one type specification (the <vector>/<scalar>/... part) is needed in general for the value entries, and no type specifications are needed if the function is scalar.
