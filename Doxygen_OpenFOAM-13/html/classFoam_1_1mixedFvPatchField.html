Detailed Description

template<class Type>
class Foam::mixedFvPatchField< Type >

This boundary condition provides a base class for 'mixed' type boundary conditions, i.e. conditions that mix fixed value and patch-normal gradient conditions.

The respective contributions from each is determined by a weight field:

where

= patch values
= patch internal cell values
= weight field (0-1)
= inverse distance from face centre to internal cell centre
Usage
Property Description Required Default value
refValue reference value yes
refGradient reference normal gradient yes
valueFraction weight field yes

Note: This condition is not usually applied directly; instead, use a derived mixed condition such as inletOutlet

See also
Foam::inletOutletFvPatchField
