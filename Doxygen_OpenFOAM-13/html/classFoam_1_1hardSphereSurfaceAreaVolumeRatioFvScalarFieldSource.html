Detailed Description

This source condition creates an interfacial mass transfer source term in the surface-area-to-volume-ratio (kappa) equations of the fractal shape model of population balance, using a hard-sphere assumption.

Usage
Example of the source condition specification: 
<sourceName>
{
    type            hardSphereSurfaceAreaVolumeRatio;
    libs            ("libmultiphaseEulerFvModels.so");
}
