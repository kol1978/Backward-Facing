Detailed Description

Base class for ignition kernel flame wrinkling Xi correction.

Usage
Example usage: 
XiCorr
{
    type            <type>;
    cellZone        all;
    bMin            0.05;
}

Where:

Property Description Required Default value
cellZone Correction cellZone yes
bMin Min b below which no correction no 0.01
