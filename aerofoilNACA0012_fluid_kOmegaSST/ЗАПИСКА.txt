 
inGroups List<word> 1(freestream); — это группа патчей. Здесь сказано, что патч inlet входит в группу с именем freestream.
Группы нужны, чтобы в словарях полей (в 0/*) можно было задавать граничные условия сразу для нескольких патчей одним блоком, например:
foam
boundaryField
{
    freestream
    {
        type fixedValue;
        value uniform (200 0 0);
    }
}
Тогда условие применится ко всем патчам, у которых в inGroups есть freestream (в том числе к inlet, а может быть ещё farField и т. п.).
