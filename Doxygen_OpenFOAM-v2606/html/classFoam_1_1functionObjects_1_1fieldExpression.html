Detailed Description

Intermediate class for handling field expression function objects (e.g. blendingFactor etc.) whereinto a single field is input.

Usage
Minimal example by using system/controlDict.functions: 
FOname
{
    // Mandatory and optional entries
    ...

    // Mandatory entries
    field             <word>;

    // Optional entries
    result            <word>;
    cellZones         (<word> <word> ... <word>);
}

where the entries mean:

Property Description Type Reqd Deflt
field Name of the operand field word yes -
result Name of the output field word no <FO>(<field>)
cellZones Names of cellZones wordRes no -
