Detailed Description

template<class CloudType>
class Foam::RemoveParcels< CloudType >

Removes parcels that hit user-specified face zone faces.

Example usage: 

removeParcels1
{
    type            removeParcels;
    log             yes;
    resetOnWrite    no;
    resetOnStart    no;
    faceZones       (cycLeft cycRight);
}
