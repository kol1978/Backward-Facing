Read points from a (.vrt) file, return the max prostar id used.

The file format is as follows: 

* Line 1:
* PROSTAR_VERTEX  newline
* 
* Line 2:
* {version} 0 0 0 0 0 0 0  newline
* 
* Body:
* {vertexId}  {x}  {y}  {z}  newline
*
