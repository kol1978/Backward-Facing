Detailed Description

User specification of a coordinate rotation. 

rotation
{
    type    axes
    e1      (1 0 0);
    e2      (0 1 0);
}

Types of coordinateRotations:

  1. none
  2. axes
  3. axisAngle
  4. cylindrical
  5. euler
  6. starcd
