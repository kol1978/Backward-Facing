33Description
34 Calculates various statistics of the specified fields.
35
36 Operands:
37 \table
38 Operand | Type | Location
39 input | vol<Type>Field(s) | Registry
40 output file | dat | postProcessing/<FO>/<time>/file
41 output field | - | -
42 \endtable
43
44 where \c Type can be one of:
45 \c Scalar, \c Vector, \c SphericalTensor, \c SymmTensor, or \c Tensor.
46
47Usage
48 Minimal example by using \c system/controlDict.functions:
49 \verbatim
50 fieldStatisticsFO
51 {
52 // Mandatory entries
53 type fieldStatistics;
54 libs (fieldFunctionObjects);
55 fields (<wordList>);
56 statistics (<wordList>);
57
58 // Optional entries
59 mode <word>;
60 mean <word>;
61 extrema <bool>;
62 internal <bool>;
63
64 // Inherited entries
65 ...
66 }
67 \endverbatim
68
69 where the entries mean:
70 \table
71 Property | Description | Type | Reqd | Deflt
72 type | Type name: fieldStatistics | word | yes | -
73 libs | Library name: fieldFunctionObjects | word | yes | -
74 fields | List of operand fields | wordList | yes | -
75 statistics | List of operand statistics | wordList | yes | -
76 mode | Output format of the statistical results | word | no | magnitude
77 mean | Type of the mean operation | word | no | arithmetic
78 internal | Flag to use internal fields only in computing statistics <!--
79 --> | bool | no | false
80 extrema | Flag to enable extrema data calculations | bool | no | false
81 \endtable
82
83 The inherited entries are elaborated in:
84 - \link functionObject.H \endlink
85 - \link writeFile.H \endlink
86
87 Available statistics of the operand field through the \c statistics entry:
88 \verbatim
89 min | Minimum value
90 max | Maximum value
91 mean | Arithmetic mean value (optionally volume-weighted)
92 variance | Sample variance value (unbiased)
93 \endverbatim
94
95 Options for the \c mode entry:
96 \verbatim
97 magnitude | Output statistics magnitude-wise
98 component | Output statistics separately for each component
99 \endverbatim
100
101 Options for the \c mean entry:
102 \verbatim
103 arithmetic | Arithmetic mean (average)
104 volumetric | Volume-weighted arithmetic mean
105 \endverbatim
106

108 fieldStatistics.cxx
109 fieldStatisticsImpl.cxx
