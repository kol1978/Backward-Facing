Detailed Description

A centralized collection of named coordinate systems.

Note
Mixing normal constructors and the coordinateSystems::New constructor may yield unexpected results.
cat1
{
    coordinateSystem
    {
        type   indirect;
        name   _10;
    }
    porosity    0.781;
    Darcy
    {
        d   d [0 -2 0 0 0]  (-1000 -1000 0.50753e+08);
        f   f [0 -1 0 0 0]  (-1000 -1000 12.83);
    }
}

For this to work correctly, the coordinateSystem constructor must be supplied with an objectRegistry as well as the dictionary.
