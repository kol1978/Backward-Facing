Detailed Description

A critical heat flux (CHF) sub-cooling correlation model.

Usage
Example of the model specification: 
CHFSubCoolModel
{
    // Mandatory entries
    type            Tatsumoto;

    // Optional entries
    K               <scalar>;
}

where the entries mean:
