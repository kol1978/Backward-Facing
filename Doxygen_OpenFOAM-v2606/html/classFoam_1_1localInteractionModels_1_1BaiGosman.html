Detailed Description

template<class CloudType>
class Foam::localInteractionModels::BaiGosman< CloudType >

Internal BaiGosman thermo parcel-patch interaction used by Foam::LocalInteraction.

Requires a parcel type exposing T() and rho() (thermo / reacting clouds) and an SLGThermo with at least one liquid component registered on the cloud's database. Splash parcels are added to the owner cloud immediately via Cloud::addParticle.
