Detailed Description

template<class Type>
class Foam::fv::skewCorrectedSnGrad< Type >

Surface gradient scheme with skewness and full explicit non-orthogonal corrections.

Usage
Minimal example by using system/fvSchemes: 
snGradSchemes
{
    snGrad(<term>)       skewCorrected;
}
