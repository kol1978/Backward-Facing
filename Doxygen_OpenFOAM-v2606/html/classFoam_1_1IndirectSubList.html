Detailed Description

template<class T>
class Foam::IndirectSubList< T >

Indirect access to a sub-section of a list.

In many cases, using a Foam::SubList provides a simpler and more efficient means of accessing a sub-list. With an IndirectSubList, however, can recover the original underlying list at any time.

See also
Foam::SubList
