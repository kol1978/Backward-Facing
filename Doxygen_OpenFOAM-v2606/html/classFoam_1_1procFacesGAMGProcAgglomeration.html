Detailed Description

Processor agglomeration of GAMGAgglomerations.

Combines processors into master processors by agglomerating across processor boundaries. Works in one of two modes:

  • if nMasters (or nProcessorsPerMaster) is given, agglomerate the coarsest level until that number of processors (or cores per master) is reached. This is very much like masterCoarsestGAMGProcAgglomeration but agglomerating only connected procesors.
  • if nAgglomeratingCells is given, agglomerate all levels once until the number of cells on any processor is below that number.

E.g.

p { solver GAMG; ...

processorAgglomerator procFaces; Agglomerate until 4 master processors are reached nMasters 4; }

Implementation: processors get agglomerated by constructing an equivalent lduMesh where each processor is a cell and each processorInterface is a face. This mesh then gets agglomerated using the standard pairGAMGAgglomeration algorithm with the number of faces on the original processor interface as face weight. The nMasters controls the number of pair-wise agglomeration ('mergeLevels').
