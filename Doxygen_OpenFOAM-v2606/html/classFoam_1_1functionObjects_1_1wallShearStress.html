Detailed Description

Computes the wall-shear stress at selected wall patches.

where

= Wall shear stress vector [m^2/s^2]
= Shear-stress symmetric tensor (retrieved from turbulence model)
= Patch normal vector (into the domain)

Operands:

Operand Type Location
input - -
output file dat postProcessing/<FO>/<time>/field
output field volVectorField (only boundaryField) <time>/outputField
Usage
Minimal example by using system/controlDict.functions: 
wallShearStressFO
{
    // Mandatory entries
    type            wallShearStress;
    libs            (fieldFunctionObjects);

    // Optional entries
    patches         (<patch1> ... <patchN>); // (wall1 "(wall2|wall3)");
    writeFields     <bool>;

    // Inherited entries
    ...
}

where the entries mean:

Property Description Type Reqd Deflt
type Type name: wallShearStress word yes -
libs Library name: fieldFunctionObjects word yes -
patches Names of operand patches wordRes no all wall patches
writeFields Flag to write shear stress field bool no true

The inherited entries are elaborated in:

  • functionObject.H
  • writeFile.H
Note
The writeFields flag currently defaults to true (for consistency with previous versions that did not have that flag) but this is subject to change in the near future for consistency with other function objects.
