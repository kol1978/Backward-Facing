28Class
29 Foam::functionObjects::fieldMinMax
30
31Group
32 grpFieldFunctionObjects
33
34Description
35 Computes the values and locations of field minima and maxima.
36 These are good indicators of calculation performance, e.g. to confirm that
37 predicted results are within expected bounds, or how well a case is
38 converging.
39
40 Multiple fields can be processed, where for rank > 0 primitives, e.g.
41 vectors and tensors, the extrema can be calculated per component, or by
42 magnitude. In addition, spatial location and local processor index are
43 included in the output.
44
45 Operands:
46 \table
47 Operand | Type | Location
48 input | - | -
49 output file | dat | postProcessing/<FO>/<time>/file
50 output field | - | -
51 \endtable
52
53Usage
54 Minimal example by using \c system/controlDict.functions:
55 \verbatim
56 fieldMinMaxFO
57 {
58 // Mandatory entries
59 type fieldMinMax;
60 libs (fieldFunctionObjects);
61 mode <word>; // magnitude;
62 fields (<wordList>); // (<field1> <field2> ... <fieldN>);
63
64 // Optional entries
65 location <bool>;
66
67 // Inherited entries
68 ...
69 }
70 \endverbatim
71
72 where the entries mean:
73 \table
74 Property | Description | Type | Reqd | Deflt
75 type | Type name: fieldMinMax | word | yes | -
76 libs | Library name: fieldFunctionObjects | word | yes | -
77 fields | List of operand fields | wordList | yes | -
78 location | Write location of the min/max value | bool | no | true
79 mode | Calculation mode: magnitude or component | word | no | magnitude
80 internal | Internal fields only for the calculations | bool | no | false
81 \endtable
82
83 The inherited entries are elaborated in:
84 - \link functionObject.H \endlink
85 - \link writeFile.H \endlink
