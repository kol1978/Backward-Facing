Detailed Description

The filmSeparation is a collection of curvature thin-film separation models designed to predict the onset of film separation and mass separation in geometries featuring sharp and/or rounded corners.

Usage
Minimal example by using boundary-condition files: 
injectionModels
{
    // Mandatory entries
    filmSeparation
}

filmSeparationCoeffs
{
    model           <word>;

    // Conditional entries

        // Option-1: when model == OwenRyley

        // Option-2: when model == Friedrich

    // Inherited entries
    ...
}

where the entries mean:

Property Description Type Reqd Deflt
model Name of the filmSeparation model word yes -

Options for the model entry: 

      OwenRyley    | Model proposed by Owen-Ryley (1985)
      Friedrich    | Model proposed by Friedrich et al. (2008)
