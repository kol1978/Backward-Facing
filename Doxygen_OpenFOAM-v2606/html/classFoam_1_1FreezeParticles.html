Detailed Description

template<class CloudType>
class Foam::FreezeParticles< CloudType >

Sets particle active flag to false to freeze particles in space.

Usage
Minimal example by using constant/<CloudProperties>: 
cloudFunctions
{
    FreezeParticles
    {
        // Mandatory entries
        type    FreezeParticles;
    }
}

where the entries mean:

Property Description Type Reqd Deflt
type Type name: FreezeParticles word yes -
