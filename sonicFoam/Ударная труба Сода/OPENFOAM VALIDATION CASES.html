ТЕСТЫ ДЛЯ ВАЛИДАЦИИ OPENFOAM

Ударная труба Сода

В этом тесте мы моделируем ударную трубу Сода. Уравнения, которые необходимо решить, — это уравнения Эйлера, а воздух моделируется как идеальный газ. Это чрезвычайно сложный тест, который используется для проверки точности и стабильности решателей вычислительной гидродинамики. Точное решение этой задачи можно получить с помощью точных решателей Римана [1, 2].

Сравнение численного решения с точным. Решения сравниваются при физическом времени 0,1 секунды и на одной линии по горизонтальной оси.
