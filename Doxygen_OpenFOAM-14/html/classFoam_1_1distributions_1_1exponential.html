Detailed Description

Exponential distribution, scaled so that it spans between a specified minimum and maximum value, rather than from zero to infinity.

Usage
Example usage: 
{
    type    exponential;
    Q       3;
    min     0.01;
    max     0.5;
    lambda  3;
}
