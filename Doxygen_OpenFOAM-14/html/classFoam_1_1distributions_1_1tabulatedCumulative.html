Detailed Description

Distribution in which the cumulative distribution function is given as a table of values.

Usage
Example usage: 
{
    type    tabulatedCumulative;
    Q       0;
    distribution
    (
        (10e-6 0)
        (12e-6 0.1972235)
        (15e-6 2.6711166)
        (19e-6 11.643361)
        (25e-6 28.968245)
        (31e-6 52.155796)
        (39e-6 74.381959)
        (50e-6 91.162850)
        (63e-6 100)
    );
}
