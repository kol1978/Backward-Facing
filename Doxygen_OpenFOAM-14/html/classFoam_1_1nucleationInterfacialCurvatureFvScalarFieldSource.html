Detailed Description

This source condition creates a nucleation source term in the interfacial curvature equations of the IATE model. The fvSource it relates to should be a nucleation model.

Usage
Example of the source condition specification: 
<sourceName>
{
    type            nucleationInterfacialCurvature;
    libs            ("libmultiphaseEulerFvModels.so");
}
