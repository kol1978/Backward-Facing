Detailed Description

template<class Type>
class Foam::calculatedLagrangianPatchField< Type >

A calculated boundary condition for Lagrangian. This condition does not provide any evaluation functionality. It simply retains the values that were created as a result of the solution of the internal field.

Usage
Example specification: 
<LagrangianPatchName>
{
    type            calculated;
}
