Комбинированные измерения расхода и отклонения вызванных FSI колебаний двух жестких конструкций в турбулентных потоках

Эксперименты Перейры Гомеша и Лиенхарта

Описание

Характеристика вызванных FSI двумерных колебаний с предельным циклом (LCO) двух жестких конструкций при чистом вращении в равномерных потоках. Измерения проводились в воде при постоянной скорости течения 1,07 м/с.

Полное описание данного набора экспериментов доступно в виде PDF-файла: c_data_description.pdf.

Геометрические параметры

Определение модели

Структурные модели представлены на рисунке 1. Первая модель состояла из простой плоской пластины, армированной углеродным волокном, толщиной 2 мм. Вторая модель состояла из переднего алюминиевого цилиндра диаметром 22 мм с прикрепленной плоской пластиной. Для простоты в этой модели использовалась такая же пластина, то есть пластина из углеродного волокна толщиной 2 мм. Общая длина моделей была определена как 64 мм, а поперечный размер был выбран равным поперечному размеру испытательного участка, чтобы гарантировать двумерность экспериментов. Между моделями и стенками испытательного участка был оставлен небольшой зазор в 1,5 мм, чтобы избежать возможного трения между движущимися моделями и стенками.

Определение области течения

Измерения проводились в вертикальном замкнутом водном туннеле. Пространственные размеры испытательного участка туннеля показаны на рисунке 3. Его поперечное сечение составляло 180 мм x 240 мм, а общая длина — 380 мм. Поскольку туннель был расположен вертикально, сила тяжести была направлена вдоль потока (ось xx, см. рисунок 3). Таким образом, сила тяжести не привносила никакой асимметрии в эксперименты. Все тестовые модели были установлены на расстоянии 55 мм ниже входной плоскости испытательного участка со свободной степенью свободы вращения. Опорная система состояла из двух подшипников с низким коэффициентом трения и была спроектирована таким образом, чтобы обеспечить свободное вращение модели вокруг оси zz (см. рис. 3).

Подробности эксперимента

Измерения поля течения

Поле скорости течения измерялось с помощью двумерной двухкомпонентной системы визуализации частиц DANTEC (PIV). Для получения изображений были использованы две синхронизированные ПЗС-камеры с разрешением 1280 x 1024 пикселей, оснащенные макрообъективами с фокусным расстоянием 60 мм. Они позволили получить две одновременные и смежные пары изображений, зависящих от времени, из центральной плоскости тестового образца (плоскость x−yx−y, см. рис. рис. 3). Изображения, полученные с помощью метода PIV, были импортированы в скрипт постобработки на базе MatLab для совмещения соответствующих пар изображений перед их корреляцией. Благодаря этому решению удалось увеличить площадь измерения поля потока до 270 мм x 170 мм, сохранив при этом пространственное разрешение измерений на уровне 7,53 пикселя ПЗС на мм.

Для освещения потока с обеих сторон испытательного участка использовались два лазерных источника света, каждый из которых освещал поток с одной стороны модели, чтобы избежать образования теневых участков в потоке. Лазеры были двухголовочные, импульсные, на основе Nd:YAG, и генерировали световые импульсы с длиной волны 532 нм и максимальной энергией 120 мДж.

В качестве затравки были выбраны полые стеклянные сферы со средним диаметром 10 мкмμ.

Реконструкция измерений в пространственно-временном представлении

Измерительная система работала с постоянной частотой сбора данных, а реконструкция измерений во временно-фазовом пространстве выполнялась в период постобработки. Такой подход был выбран вместо того, чтобы запускать сбор данных в ходе эксперимента, чтобы синхронизировать его с обычными колебаниями периода колебаний структуры, наблюдаемыми при испытаниях на свободные колебания. На рисунке 4 показана типичная реконструкция данных с использованием этого метода. Одновременно с получением данных измерений фиксировались два типа событий: получение данных измерений tmitmi [рис. 4(B)] и начало циклов движения tcjtcj [рис. 4(A)]. Эти временные события определялись с помощью триггерного сигнала камеры и сигнала датчика углового положения, расположенного на вращающейся оси конструкции, соответственно.

Рис. 4. Схема реконструкции измерений с временным и фазовым разрешением

Мониторинг событий осуществлялся с помощью аппаратного модуля, разработанного на основе программируемой пользователем вентильной матрицы (ППВМ) и внутреннего тактового генератора с частотой 1 МГц. Модуль мог регистрировать до 250 событий в секунду с точностью до 2 мксμ.

На основе информации о времени зарегистрированных событий программное обеспечение для постобработки вычисляло фазовый угол ϕϕ для каждого полученного измерения. На этом этапе разрешенные измеренные данные можно было упорядочить в соответствии с эталонным периодом, равным среднему периоду всех полученных циклов [рис. 4(C)], и отсортировать по заранее заданному разрешению по углу фазы во времени и погрешности [рис. 4(D)]. Наконец, данные, попадающие в один диапазон угла фазы во времени, усреднялись для получения окончательного результата [рис. 4(E)]. В представленных тестовых примерах реконструкция экспериментальных результатов проводилась с временным разрешением и погрешностью 5o и 0,5o соответственно, а итоговый результат соответствовал среднему значению 100 реализаций.

Наконец, следует принять во внимание, что на результаты, полученные с помощью компьютерной модели, повлияла несущая система конструкции. В данном случае конструкция была недостаточно большой, чтобы перекрывать изображение держателя подшипника, поэтому часть поля течения, соответствующая окружности диаметром 13 мм вокруг начала координат, была недоступна для оптических средств наблюдения.
