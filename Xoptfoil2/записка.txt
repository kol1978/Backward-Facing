# Начало работы

Добро пожаловать. В этом руководстве вы познакомитесь с первым этапом оптимизации аэродинамического профиля. Вам пока не нужно вникать во все детали — цель состоит в том, чтобы получить первое практическое представление о рабочем процессе.
{: .fs-6 .fw-300 }

## Задача оптимизации

В качестве отправной точки мы используем хорошо известный аэродинамический профиль SD7003. SD7003 — это классическая низкоскоростная конструкция, часто используемая в малых масштабах. Он часто используется в качестве законцовки крыла в семействах аэродинамических профилей, где разные секции оптимизированы для разных участков крыла (такая практика называется «стракинг»).

![SD7003](../images/getting_started_SD7003.png)

В нашем примере мы адаптируем SD7003 для использования на всем крыле. Корневая часть (там, где крыло соединяется с фюзеляжем) работает при более высоких числах Рейнольдса, чем законцовка, поэтому нам нужно немного изменить форму, чтобы сохранить хорошие аэродинамические характеристики. Наша цель — создать сбалансированную конструкцию, которая будет одновременно быстрой и эффективной.

Вот чего мы хотим добиться:
1. Оптимизация аэродинамического профиля для числа Рейнольдса 400 000 (типичного для корневой части крыла)
2. Минимизировать лобовое сопротивление при коэффициенте подъемной силы 0,2
3. Сохранить то же удлинение по горизонтали, что и у оригинального SD7003, при коэффициенте подъемной силы 0,7
4. Сохранить толщину 8%

Традиционно этот процесс выполняется путем ручной настройки параметров геометрии в таком инструменте, как XFLR5, и тестирования каждого варианта. Xoptfoil2 выполняет этот поиск автоматически.

## Скачайте и запустите Xoptfoil2

Загрузите Xoptfoil2 из раздела [Релизы] (https://github.com/jxjo/Xoptfoil2/releases ) на GitHub. В разделе "Активы" вы найдете:
- Готовая к запуску версия Windows
- Исходные файлы для сборки в Linux

<span>Windows</span>{: .label .метка-синяя }
Скачайте zip-файл для Windows и распакуйте его в любом месте — для тестирования подойдет рабочий стол. Xoptfoil2 — легковесный инструмент, который не засоряет систему зависимостями. Перейдите в папку `.\examples\SD7003_fast` и дважды щелкните файл `make.bat`, чтобы запустить его.


<span>Linux</span>{: .label .label-red }
См. [руководство по установке]({% link run_xoptfoil2/install.md %}#installation) для сборки Xoptfoil2 из исходного кода. После сборки откройте терминал в `./examples/SD7003_fast` и выполните:
```
xoptfoil2 -i SD7003_fast.xo2
```

Затем начинается оптимизация. Вы увидите прокручивающийся список для каждой итерации. Каждая строка содержит символы `+`, `-` и `x` для различных частиц (возможных конструкций) в поиске. Зеленый ** `+` ** отмечает лучший дизайн, найденный на данный момент.


## Просматриваем результаты.

Примерно через минуту оптимизация завершится. Результаты должны соответствовать (1) на скриншоте ниже.:

![XO2 Первый запуск](../images/getting_started_first_run.png)

Откройте оба профиля в [Airfoil Editor](https://github.com/jxjo/AirfoilEditor) или XFLR5 — исходный SD7003.dat и оптимизированный SD7003_fast.dat — и сравните их геометрию (2):
- **Толщина**: теперь 8%, как и требовалось ✓
- **Расположение максимальной толщины**: без изменений (оптимизатор сохранил то, что работало)
- **Расположение максимального изгиба**: смещено с 33% до 45% хорды для работы при более высоких числах Рейнольдса
Сгенерируйте полярную диаграмму T1 в [Airfoil Editor](https://github.com/jxjo/AirfoilEditor) или XFLR5 для Re=400 000 при ncrit=9. Результаты (3) показывают:
- **Снижение аэродинамического сопротивления**: при cl=0,2 сопротивление снизилось примерно на 7%.
- **Коэффициент планирования**: при cl=0,7 коэффициент планирования оставался на заданном уровне.

Теперь предположим, что приоритеты вашего проекта изменились: скорость важнее чистой эффективности. В следующем запуске показано, как адаптировать настройки.

## Лети быстрее!

Далее мы настроим тот же аэродинамический профиль для большей скорости.

Откройте входной файл `SD7003_fast.xo2` в любом текстовом редакторе и внесите два небольших изменения:

1. **Снизить целевое значение аэродинамического качества**: Уменьшите целевое значение аэродинамического качества для второй рабочей точки: Изменить
`target_value(2) = 74` на `target_value(2) = 70`.
2. **Уменьшить толщину**: изменить `target_geo(1) = 0.080` на `target_geo(1) = 0.075`. Более тонкий аэродинамический профиль обычно имеет меньшее сопротивление при более низких скоростях.

Сохраните файл и снова запустите оптимизатор, чтобы оценить обновленные приоритеты.

## Что делать дальше?

Несмотря на то, что этот пример кажется простым, геометрия аэродинамического профиля и его аэродинамическое поведение — обширные темы. По мере дальнейшего изучения — добавления новых рабочих точек, экспериментов с ограничениями, опробования различных функций формы — вы будете лучше понимать, что возможно, а что нет.

{: .tip }
 Совет: включите параметр `show_details` во входном файле, чтобы отображалась дополнительная информация для каждого этапа оптимизации.

Для более подробного ознакомления перейдите к главе [Оптимизация аэродинамического профиля]({% link airfoil_optimization/overview.md %}) . В ней рассматриваются функции формы, рабочие точки и дополнительные возможности.
